# Cartella immagini

Nella Fase 1 **non servono immagini**: mago, nemici, note, magie e tastiera sono
disegnati a runtime con forme geometriche (Canvas), quindi il gioco è giocabile
senza alcuno sprite.

Se in futuro vuoi sostituire i placeholder con sprite veri, inseriscili qui e
caricali tramite `Sprite.load('nome_file.png')` di Flame.

> Usa solo asset liberi (CC0/Public Domain) o creati da te. Niente copyright.
